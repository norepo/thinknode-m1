<a id="english"></a>
## English
Precompiled **MeshCore 1.18** Companion Radio firmware with USB Serial interface for the **Elecrow ThinkNode M1**.

### Included Files
- `firmware.uf2`: Drag-and-drop firmware for Adafruit / nRF52 bootloader.
- `firmware.hex`: Full Intel HEX image for programmer / J-Link.
- `firmware.zip`: DFU package for `adafruit-nrfutil`.
